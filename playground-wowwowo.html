Exportable 3D Chrome Text Generator

gemini

Description

  • A simple webapp that allows user to enter text that will be displayed in a 3D chrome effect. User can also export the code to embed into their own website.

Why I created this

  • There has been a bit of a phase where new companies are adding in 3D effects but when people try it out, they're blocked by a paywall. I wanted to see how difficult it would be to create one of the many 3D effects I saw and see if it could be exportable.

Issues I encountered

  • I had many issues to get having the ability for the user to drag and rotate the words but it has now been fixed.

What I learned

  • We may not have the ability or amount of tokens to create all the intricate effects we see but if there's a specific effect one particularly wants to use, AI can definitely help build it as close it can to it and free.
