Exportable 3D Chrome Text Generator

gemini

Description

  • A simple web app that lets a user enter text and see it rendered in a 3D chrome effect. Users can also export the code to embed into their own website.

Why I created this

  • There’s been a bit of a phase where companies add 3D effects, but when people try them out they’re blocked by a paywall. I wanted to see how difficult it would be to create one of the many 3D effects I’d seen, and whether it could be made exportable.

Issues I encountered

  • I ran into a lot of issues getting the ability for users to drag and rotate the words, but it’s now been fixed.

What I learned

  • We may not have the ability, or enough tokens, to create every intricate effect we see — but if there’s one specific effect you want to use, AI can definitely help build it as close as possible, and for free.
