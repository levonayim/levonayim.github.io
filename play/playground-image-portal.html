Image Portal

claude code

Description

  • A simple web app where users have multiple images in a gallery, with a portal effect to look into the next one.

Why I created this

  • I was inspired by an image I saw in a Figma ad, where a transparent glass sat in the middle of a photo. Aesthetically it looked nice, but I wasn’t sure what its purpose was — so I asked Claude Code to replicate it in code, and make it more “useful” by making it feel like the user is moving through to the next image.

Issues I encountered

  • As a standalone app, it’s limited to the host’s own images. It would be nice if users could add their own images, or have AI curate different images depending on the “mood” or category they want to see.

What I learned

  • Sharing images of inspiration with Claude Code can be much more useful than typing out the prompt.
  • Where it might have taken me weeks to figure out the base of this code, Claude Code did it in a few minutes.
