Data Schema Prototype

claude code cursor figma

Description

  • Using Claude Code and Cursor to create a fully interactive prototype of data schemas.

Why I created this

  • While I was at FICO, I worked on the Business Terms Capability project but with many technical constraints — I was restricted by time, technical ability, and the security requirements of the team. I wanted to show that the designs I create don’t need to be plain tables.
  • Seeing the capability of, and learning to use, Claude Code and Cursor.

Issues I encountered

  • To make this prototype more extensive and complex, it required quite a fair amount of tokens for Claude Code and took some time to run (~25 minutes to build). This was also one of the first complex projects I built using Claude Code x Cursor, so a lot of it was setup and figuring out exactly what I wanted to create.
  • Some of the interactions on the canvas are a bit buggy (e.g. deselecting a tile).

What I learned

  • This was one of the first complex projects I built using Claude Code x Cursor, and after a couple prompts I had a very complex, real-life prototype.
  • Even though I only sent a few static screens, Claude was able to interpret the flow itself and add the interactions.
  • I understand that even though this prototype doesn’t have all the functionality of a real platform, it can get to an even further point, and faster, than if it was just me designing and prototyping everything by hand.
