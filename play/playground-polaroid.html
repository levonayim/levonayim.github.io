Polaroid Effect — Web + Mobile

claude gemini html/css/js

Description

  • A web app that lets users upload 1–3 photos, where they can add filters, adjust the image, and add a polaroid frame around it.

Why I created this

  • At the time I made this (June 2026), Instagram didn’t have a polaroid-frame feature.
  • Instagram’s current polaroid effect is limited to one size of polaroid.
  • On Instagram, users can’t adjust the image within the frame.

Issues I encountered

  • Depending on the photo’s dimensions and the sizing of the polaroid, it can squish the image.
  • When downloading the image, it defaults to the same file name.

What I learned

  • Even though Instagram’s newest update lets users add a polaroid effect to photos, I prefer using mine since I can adjust the photo and I’m not limited on sizing.
  • A lot of patience is needed when prompting the AI to fix the photo-adjustment behaviour.
